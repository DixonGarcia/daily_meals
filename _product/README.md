# DailyMeals - Product Features

This directory contains the specifications, user stories, and acceptance criteria for each feature of the DailyMeals application.

## Directory Structure
Every feature we build has a corresponding specification file here in `_product/`. For example:
- `_product/inventory_management/specification.md`
- `_product/meal_planning/specification.md`
- `_product/shopping_list/specification.md`
- `_product/ai_copilot/specification.md`
- `_product/dashboard/specification.md`

## Specification Template
Each feature specification should contain:
1. **Description**: What is this feature? What problem does it solve?
2. **User Stories**: As a [role], I want [action] so that [benefit].
3. **Acceptance Criteria**: Gherkin-style Given/When/Then scenarios.
4. **Data Model Changes**: Any new models, fields, or database relationships required.
